Supplementary tables for the manuscript

> **Bi-CAC: A Bi-Level Cooperative Actor-Critic Framework with Cross-Tier Attention

## Contents

* **S1 — Model formulation and complete notation.** Table S1 lists every symbol of the model; the feasible
  set is restated as constraints (C1)–(C7).
* **S2 — Instance generator and training configuration.** Table S2 gives the individual settings.
* **S3 — Per-scale statistics.** Table S3 reports makespan (mean ± std) and the average gap for the eleven
  methods; Table S4 restates the same records as a per-scale gap.
* **S4 — Methods and rule primitives.** Table S5 lists the eleven methods, Table S6 defines the seven
  primitives crossed by rules R1–R6.
* **S5 — Ablation variants.** Table S7 states what each variant changes and which component it isolates.
* **S6 — Convergence summary.** Table S8 gives the first-50 and last-50 episode makespan per learner.
* **S7 — Two derivations.** The telescoping of the dense reward in (12) and the per-decision
  cost of the network.

Section, equation, figure and table numbers without the `S` prefix refer to the main text.
